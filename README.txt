FASTEST IPHONE SETUP WITH GITHUB PAGES
1. Create a new GitHub repository, e.g. run-strength.
2. Upload ALL files from this folder to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Choose branch "main" and folder "/ (root)", then Save.
6. Open the HTTPS Pages address GitHub gives you in Safari on your iPhone.
7. Tap Share > Add to Home Screen > Add.

The app stores your current run week and lifting log entries on the device and works offline after its first successful load.

Finisher timing: 3 x 2:30 work + 2 x 1:00 rest = 9:30 total.
